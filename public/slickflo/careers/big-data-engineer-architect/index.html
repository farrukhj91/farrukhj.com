Big Data Engineer & Architect

Islamabad, Pakistan5+ yearsPosted 30 October 2026

Overview

We are looking for an experienced Big Data Engineer and Data Platform Specialist with 5+ years of professional experience and hands-on expertise in Databricks and/or Cloudera. The ideal candidate will have strong programming skills in Python and Java, experience with distributed data processing, and the ability to design, develop, and optimize scalable data pipelines and enterprise data platforms.

Key Skills

DatabricksClouderaApache SparkPythonJavaSQL

Responsibilities

  • Design, develop, and maintain scalable data pipelines for processing large volumes of structured and unstructured data.
  • Build and optimize ETL/ELT workflows using Databricks, Apache Spark, PySpark, Python, and SQL.
  • Develop and maintain data processing applications and integrations using Java and relevant big data frameworks.
  • Implement and manage big data solutions using Cloudera Data Platform (CDP), Hadoop, Hive, and related technologies.
  • Optimize data processing performance, troubleshoot technical issues, and ensure data quality, reliability, and security.
  • Collaborate with data engineers, architects, and other stakeholders to deliver scalable and efficient data solutions.

Requirements

  • 5+ years of professional experience in data engineering, big data, or data platform development.
  • Hands-on experience with Databricks and/or Cloudera.
  • Strong programming proficiency in Python and Java.
  • Experience with Apache Spark, PySpark, and distributed data processing.
  • Strong SQL skills and experience developing ETL/ELT pipelines.
  • Knowledge of big data technologies such as Hadoop, Hive, and Delta Lake.
  • Experience integrating data from multiple sources and optimizing data workflows.
  • Strong analytical, troubleshooting, and problem-solving skills.

Preferred Skills

  • Familiarity with Apache Kafka and real-time data streaming architectures.
  • Knowledge of Scala or other relevant programming languages.
  • Experience with cloud platforms such as AWS, Microsoft Azure, or Google Cloud.
  • Exposure to data governance, workflow orchestration, and data platform administration.
